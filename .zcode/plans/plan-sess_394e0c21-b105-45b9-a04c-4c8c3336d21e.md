## 整体架构设计

### 数据模型重构

当前所有状态是全局变量，多图模式下需要重构为**按图片隔离**：

```js
// 每个图片的数据单元
const imageData = {
  id: 'img_xxx',
  name: 'filename.jpg',
  img: HTMLImageElement,       // 已加载的图片对象
  annotations: [],             // [{id, type, x, y, w, h, text}]
  nextId: 1,
  thumbnail: 'data:...'       // 缩略图 base64
};

// 全局状态
let images = [];               // 所有图片
let currentImageId = null;     // 当前编辑的图片 id
let history = [];              // 撤销栈 [{annotations, nextId}]
let redoStack = [];            // 重做栈
let selectedAnnotationId = null; // 当前选中的标注 id
let showGrid = false;          // 网格开关
let groupingMode = 'type';     // 'type' | 'text'
```

### 布局调整

```
┌─────────────────────────────────────────────────┐
│  Header (GitHub + 语言 + 上传 + 清空)            │
├──────┬─────────────────────────┬─────────────────┤
│左侧  │ 中间 (画布区域)          │ 右侧 (标注面板)  │
│缩略图 │  stageWrap              │  分组切换按钮    │
│列表   │  + 工具栏 (含网格开关)   │  标注列表        │
│+/-  │                        │  导出/导入按钮    │
│      │                        │  输出格式选择     │
│      │                        │  textarea 输出    │
└──────┴─────────────────────────┴─────────────────┘
```

左侧缩略图面板宽度 ~180px，可折叠（加一个折叠按钮）。

## 分步实施计划

### Step 1: 数据模型 + 多图工作流（核心基础设施）

**文件修改：index.html**

- 重构状态管理，将 `img`、`annotations`、`nextId` 迁移到 `imageData` 对象结构
- 实现 `getCurrentImage()` / `switchImage(id)` / `addImage(file)` / `removeImage(id)`
- 左侧缩略图面板 HTML + CSS（~180px，可折叠）
- 缩略图列表渲染：显示图片名 + 标注数，点击切换
- 当前图独立输出（`updateOutput()` 只输出当前图）

**关键点：**
- 切换图片时保存当前图状态，恢复目标图状态
- 画布、标注、列表全部随 `currentImageId` 变化

### Step 2: 撤销 / 重做（Ctrl+Z / Ctrl+Shift+Z）

**实现方案：**
- `pushHistory()`：在每次标注变更前调用，深拷贝 `{annotations, nextId}` 入栈
- 撤销：从 `history` pop，当前状态 push 到 `redoStack`，恢复历史快照
- 重做：从 `redoStack` pop，当前状态 push 到 `history`，恢复快照
- 限制历史栈大小（如 50 步）
- 监听 `Ctrl+Z` / `Ctrl+Shift+Z` 键盘事件

**触发撤销的变更点：**
- `addAnnotation` → `pointAt`, `finishBox`, `addManualBtn`
- `removeAnnotation`
- `clearAll`
- 标注文字修改（`input.oninput`）

### Step 3: 选中高亮 + 键盘快捷键

**选中高亮：**
- 画布上选中的点：放大圆圈 + 外发光
- 选中的框：边框加粗 + 高亮色
- 右侧列表对应项高亮背景
- 点击画布上的标注标签 → 选中；点击空白 → 取消选中

**快捷键：**
- `Delete` / `Backspace`：删除选中标注
- `Ctrl+C`：复制选中标注的坐标文本
- `Esc`：取消当前框选 / 取消选中
- `Ctrl+Z`：撤销
- `Ctrl+Shift+Z`：重做

### Step 4: 画布直接编辑标注文字

**交互流程：**
1. 双击画布上的标注标签 → 在该位置弹出输入框
2. 输入框是绝对定位的 `<input>`，覆盖在标签上方
3. 输入框失去焦点时自动保存并隐藏
4. 任何时候只能存在一个输入框（打开新输入框前关闭旧的）
5. 输入框不阻塞标注操作（鼠标点击画布其他位置时输入框自动关闭）

**实现细节：**
- 输入框是 HTML `<input>` 元素，非 SVG
- 位置通过 `canvasToStage()` 计算屏幕坐标
- 监听 `blur` 事件保存并隐藏

### Step 5: 标注吸附辅助

**Shift 键吸附：**
- 框选时按住 `Shift`：
  - 如果拖动方向接近水平（dy < dx×0.3）→ 锁定水平（dy = 0）
  - 如果拖动方向接近垂直（dx < dy×0.3）→ 锁定垂直（dx = 0）
  - 否则锁定正方形（宽高取较大值）
- 在 `updateDraft()` 中判断 `e.shiftKey` 应用吸附

**网格辅助线（可选开关）：**
- 工具栏新增「网格」按钮，点击切换
- 在 SVG overlay 中绘制网格线（基于图片自然尺寸，步长可调如 10% 或 50px）
- 网格线使用半透明细线，仅在 `showGrid=true` 时显示

### Step 6: 标注面板分组（可切换）

**分组模式切换：**
- 右侧面板头部新增「分组」按钮组：`按类型 | 按文字`
- 默认按类型（点选 / 框选两组）
- 按文字分组：相同文字归为一组，未填文字的归「未标注」

**渲染逻辑：**
- `renderList()` 根据 `groupingMode` 分组渲染
- 每组带标题头和计数
- 支持折叠/展开每组（可选）

### Step 7: 导出 / 导入标注数据

**导出 JSON：**
- 按钮「导出 JSON」→ 下载 `{imageName}_annotations.json`
- 格式：`{imageWidth, imageHeight, annotations: [{type, x, y, w, h, text}]}`

**导入 JSON：**
- 按钮「导入 JSON」→ 文件选择器
- 导入后标注追加到当前图

**输出格式（输出区切换）：**
- 当前纯文本格式（保留）
- JSON 格式（输出区显示 JSON 字符串）
- SVG 格式（生成带标注框的 SVG 字符串）
- ComfyUI 区域格式（适配 SD 区域提示词格式）
- COCO 格式（COCO JSON 格式）

输出区上方加格式选择下拉框。

## 风险评估

- **单文件体积增长**：预计从 ~660 行增加到 ~1200-1500 行，仍可控
- **多图切换时的画布状态**：需要在切换时正确保存/恢复 zoom 级别和 scroll 位置
- **撤销栈的深度拷贝性能**：`structuredClone` 或 JSON 序列化，标注数不多时无压力
- **Shift 吸附与框选的兼容性**：需确保 `e.shiftKey` 在 `mousemove` 事件中实时检测
